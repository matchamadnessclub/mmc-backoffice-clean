# MMC หลังร้าน (เฟส 1)

ระบบหลังร้าน: ล็อกอินแยกสิทธิ์ (เจ้าของ/พนักงาน), เบิกของ/นับสต๊อก, แจ้งเตือนของใกล้หมด, แก้ราคาทุนและราคาขาย

## รันในเครื่อง
1. เปิดโฟลเดอร์นี้ใน VS Code
2. เปิด Terminal ใน VS Code (เมนู Terminal > New Terminal)
3. พิมพ์ `npm install` แล้วรอจนเสร็จ
4. พิมพ์ `npm run dev`
5. เปิดเบราว์เซอร์ไปที่ http://localhost:3000

ค่าเชื่อมต่อ Supabase อยู่ในไฟล์ `.env.local` (ใส่ไว้ให้แล้ว)
